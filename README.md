# Hyperapex Business Hub

A business management platform for Hyper Apex Consultancy Firm.

## MVP scope

- Client management
- Service catalogue
- Service requests
- Task tracking
- Role-based access
- Document records
- Activity/audit logs
- Management dashboard

## Planned technology

- Frontend: HTML, CSS, JavaScript (MVP)
- Backend: Node.js + Express
- Database: MySQL
- Authentication: secure password hashing and session/token-based authentication

## Security

Do not commit passwords, API keys, database credentials, client documents, or other confidential information to this repository.

## Planned user roles

- Administrator
- Staff
- Specialist
- Client
